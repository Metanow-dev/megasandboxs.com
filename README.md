# megasandboxs.com

WordPress website template based on [WordPress core](https://github.com/WordPress/WordPress).

## Setup

1. Copy `wp-config-sample.php` to `wp-config.php` and set database credentials.
2. Point the web server document root at this directory.
3. Open the site in a browser and complete the WordPress install wizard.

## Upstream

WordPress core was imported from `https://github.com/WordPress/WordPress.git` (trunk snapshot). See `readme.html` for WordPress project documentation.
